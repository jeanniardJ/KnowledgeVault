# Polymorphism

## Related concepts

* Category: Architecture
* Topic: Object-Oriented Programming
* Difficulty: Intermediate
* Status: Draft

## Definition

Le polymorphisme est la capacité à utiliser une abstraction commune pour représenter différentes implémentations concrètes.

## Question

Qu'est-ce que le polymorphisme en [POO](./poo.md) ?

## Answer

Le polymorphisme permet de traiter des objets appartenant à des classes différentes au moyen d'une classe parente commune ou d'une interface, tout en conservant leur comportement spécifique.

## Key points

- Une interface commune définit le comportement attendu.
- Chaque implémentation peut fournir son propre comportement.
- Le code appelant n'a pas besoin de connaitre l'implémentation.
