# YAML

## YAML Ain't Markup Language

Langage avec une syntaxe basée sur l'indentation et l'utilisation de caractères spéciaux tels que les deux-points et les tirets pour définir la structure des données.

Apprécié pour sa lisibilité et sa simplicité, il est couramment utilisé dans les environnements de développement, les outils d'automatisation et les systèmes de gestion de configurations.
